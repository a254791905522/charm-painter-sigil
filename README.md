# Charm Painter Sigil

Charm Painter Sigil is an offline iPhone puzzle game where players read spirit weaknesses, draw glowing rune shapes, and restore an ancient seal across 50 local stages.

## Gameplay

The front spirit tells the player which rune is needed. Draw Flame, Frost, or Rift in the sigil area to attack, or draw Ward to restore HP. Correct charms send glowing energy into the spirit wave; missed or incorrect charms let spirits slip closer to the ward.
